# Deep module code map (read this instead of the source tree)

Folders (include from the module root, e.g. `#include "Sim/DeepRules.h"`):
- `Sim/` pure rules. `UDeepRules` = static functions (depth, zones, tether solve, winch (`WinchSpeedMps`: slower with the relic aboard), weight, swim, grab pick, Patience, settlement, fees, gates (`TryBuyHull`), bailout, salvage spots, relic, review; the helm: `HelmDepthLimitM`, `HelmStep`, `HelmParkStop`, `NearestStop`, `InHatchColumn`; home from any side: `WinchStepAroundHull` (round and under the hull, never through), `HullSlideVelocity` (pushing into the hull side slides down and under)). `UDeepMovingSubRules` = the moving sub (depth from a world Z, `ResolveWallHit`, `ParkNear`, the fixed room's `RoomSway`, the airlock's `AirlockPhase` and `ValveTurn01`; tuning `MovingSub`, `Airlock`). `DeepTuningTypes.h` = USTRUCT tuning + result types (`FDeepSubTuning` = room, hatch, console, helm, drive speed, limits). `UDeepTuningSettings` = every design number (Project Settings > Game > DEEP Tuning). Defaults are in its constructor and the struct initialisers; never add a DEEP Tuning section to `DefaultGame.ini`.
- `Game/` framework. `ADeepGameMode` (builds arena, spawns divers on the deck at `GetRoomStartTransform`, `GotoStop` = jump and park, `EnterTitle`/`StartRun`/`RestartRun`), `ADeepGameState` (Stop = loaded arena, `SubDepthM`, `bParked`, `DeepestStopReached`, Credits, HullRating = gates+1 with `HasFlashlight`/`IsHullUpgraded`/`DepthLimitM`/`ParkedStop`, DiverNumber, HullDamage, HullRepairsOwed, bOnTitle, bWon, run totals; replicated), `ADeepPlayerController` (Enhanced Input built with NewObject; `KeyHint`; menus read raw in `InputKey`; the title leaves on any key via `TryStartFromTitle`, from `InputKey` and an AnyKey action), `ADeepHUD` (owns the Slate HUD: `GatherFrame` fills one `FDeepHudFrame` per frame and raises feedback cues on state changes; the old canvas HUD `DrawLegacy` only with `Deep.HUD.Legacy 1`).
- `UI/` the HUD. `DeepHudModel` = pure: `ChooseMode` (title, aboard, helm, water, cut, dead, settlement, review, pause, settings, credits, confirm_quit) and `PanelsFor` (the one place a mode picks its panels), `FFade`, `FTween`, `BarTone`, `FHullBar`, ease-out cubic; `DeepHudLayout` = panel rects and the gauge labels (tested). `DeepHudStyle.h` = every colour by role (Primary, Secondary, Alert, Amber, PanelFill, Shade), size and time; the only file with a colour value, the legacy canvas and harpoon overlay included. `SDeepHud` = one `SLeafWidget` on the player viewport that paints the frame in `OnPaint` (Roboto via `FCoreStyle::GetDefaultFontStyle`, 1080p units under the DPI scaler). New panel: a bit in `EDeepHudPanel`, add it to `PanelsFor`, a test in `DeepHudTests.cpp`, paint it in `SDeepHud::OnPaint`. `DeepUserSettings` = the player's volume, sensitivity, invert and ray tracing (Config=GameUserSettings, saved per user) and `Content/Data/Credits.csv`; menu keys and screens are in `ADeepPlayerController::HandleMenuKey`; `Deep.Screen settings|credits|quit` opens one. `DeepHudCalm` = a pure frame filter that `SDeepHud` runs on every frame (`Calm.Apply`): the controls hint shows until first use, one prompt at a time, only critical cues (`IsCriticalCue`); hull and cargo show when they change; numbers in `FDeepHudCalmTuning`; tests `Deep.UI.HudCalm.*`.
- `Diver/` `ADeepDiver` (ACharacter: MOVE_Flying in the water, MOVE_Walking + gravity aboard via `SetAboard`; seated, the view target is the sub's helm camera; E = grab in water, use aboard; the lamp needs the flashlight), `DeepLamp` (the lamp up close: samples its whole cone, world rays + the serpent's `GetDrawnSpheres` + dressing boxes, and dims for the brightest point, `UDeepRules::LampSampleBrightness`; `Deep.Lamp.Near 1` = the old single ray; also the carried relic's glow), `UDeepTetherComponent` (TG_PostPhysics: winch, length clamp, depth from `SubDepthM`; drives the line, a `UDeepRopeComponent` (World/): a Verlet rope `Sim/DeepRopeSim` drawn as movable cylinder segments so it writes motion vectors, sags with slack (`UDeepRules::RopeShownLengthCm`), parts at the serpent's head or the hatch on a cut; the harpoon line is the same rope; DEEP Tuning > Rope; `Deep.Rope.Stage`, `Deep.Rope.State`; the line is the diver's air line (D-048): `Sim/DeepAirLineRules` pure (`PatienceAfterStep`, `StateBitesLine`, `TouchedLink`, `ReclipFee`; DEEP Tuning > Air line), `CheckSerpentBite` (server, after the line is laid: an attacking serpent's head within `BiteTouchM` of a joined rope link cuts it once, `tether_bitten`), T unclips (`UnclipKey`, its own `IMC_AirLine`) -> `UDeepRunComponent::Unclip` (Cut with `bUnclipped`: bailout air, the line hangs whole from the hatch, re-clip at the hatch is free and fires `enter_sub`); cheats in `Diver/DeepAirLineCheats.cpp`), `UDeepRunComponent` (the run state machine, below).
- `Story/` `UDeepEventBus` (`Broadcast(name, payload)`; names in `DeepEvent::` = `event` column of `Content/Data/CaptainLines.csv`), `UDeepCaptain` (picks a line, subtitle queue by urgency). Radio Captain (D-040, `Deep.Captain.Radio 0|1`): `DeepCaptainPacing` = pure scene (title/aboard/water/settlement) + danger (calm/tense/scared) -> which urgencies show in the water; the CSV `tone` column picks the line for the danger (Captain|Radio tuning; `Deep.Story.Captain*` tests).
- `Monster/` the sea serpent (see `Monster/README.md`): pure rules, settings, `UDeepMonsterBrain` (spawns at stop >= 2), `ADeepSerpent` (procedural tube body on a Verlet chain the head drags, `UDeepMonsterRules::StepChain` (drag heavier across the body than along it, no stroke: plain rope) + `ChainPoint` (Catmull-Rom centreline) + `Body.Chain`, head socket, eyeshine, markings, its own glow in a bite (`Deep.Monster.Glow 0|1`); the Dragon Cave dragon as a clipped mesh head when the pack is installed, `Deep.Monster.MeshHead 0` = code head; materials in `Content/Deep/Serpent`, rebuilt by its .py files), `ADeepSerpentController` (keeps to the relic's shaft while its diver is in it: `UDeepMonsterRules::WellAimPoint`; elsewhere every aim and the path stay `CaveWallClearM` + `CaveBodyReachM` inside the cavern: `ADeepCavern::KeepClearCm`). Lane G: it hears bus events (`sonar_ping`, `harpoon_fired`, `hull_hit`) and the helm throttle (brain, `NoiseForEvent`, `HelmNoise`), answers with a call and turns to the sound; state `Taunt` (edge of the light, brush past, withdraw, `TauntPath`, never bites) before a bite; its voice (drone, clicks, calls `serpent_*` built-ins) plays spatialised at the head on every machine from `MoodState`/`CallSerial`; `Deep.Monster.Taunt [n]`, `Deep.Monster.Call [kind]`. It only hunts divers who can swim; aboard is safe.

Sub hits raise `HullDamage` and `HullRepairsOwed` (billed once in `Bank`).

3. In the water: controller input -> diver Tick -> `SwimVelocityMps`. Tether after physics. Grab -> cargo, `NotifyPickup`.
