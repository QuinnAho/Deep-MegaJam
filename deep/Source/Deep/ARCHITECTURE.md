# Deep module code map (read this instead of the source tree)

Folders (include from the module root, e.g. `#include "Sim/DeepRules.h"`):
- `Sim/` pure rules. `UDeepRules` = static functions (depth, zones, tether solve, winch (`WinchSpeedMps`: slower with the relic aboard), weight, swim, grab pick, Patience, settlement, fees, gates (`TryBuyHull`), bailout, salvage spots, relic, review; the helm: `HelmDepthLimitM`, `HelmStep`, `HelmParkStop`, `NearestStop`, `InHatchColumn`; home from any side: `WinchStepAroundHull` (round and under the hull, never through), `HullSlideVelocity` (pushing into the hull side slides down and under)). `DeepTuningTypes.h` = USTRUCT tuning + result types (`FDeepSubTuning` = room, hatch, console, helm, drive speed, limits). `UDeepTuningSettings` = every design number (Project Settings > Game > DEEP Tuning). Defaults are in its constructor and the struct initialisers; never add a DEEP Tuning section to `DefaultGame.ini`.
- `Game/` framework. `ADeepGameMode` (builds arena, spawns divers on the deck at `GetRoomStartTransform`, `GotoStop` = jump and park, `EnterTitle`/`StartRun`/`RestartRun`), `ADeepGameState` (Stop = loaded arena, `SubDepthM`, `bParked`, `DeepestStopReached`, Credits, HullRating = gates+1 with `HasFlashlight`/`IsHullUpgraded`/`DepthLimitM`/`ParkedStop`, DiverNumber, HullDamage, HullRepairsOwed, bOnTitle, bWon, run totals; replicated), `ADeepPlayerController` (Enhanced Input built with NewObject; `KeyHint`; menus read raw in `InputKey`; the title leaves on any key via `TryStartFromTitle`, from `InputKey` and an AnyKey action), `ADeepHUD` (owns the Slate HUD: `GatherFrame` fills one `FDeepHudFrame` per frame and raises feedback cues on state changes; the old canvas HUD `DrawLegacy` only with `Deep.HUD.Legacy 1`).
- `UI/` the HUD. `DeepHudModel` = pure: `ChooseMode` (title, aboard, helm, water, cut, dead, settlement, review, pause, settings, credits, confirm_quit) and `PanelsFor` (the one place a mode picks its panels), `FFade`, `FTween`, `BarTone`, `FHullBar`, ease-out cubic; `DeepHudLayout` = panel rects and the gauge labels (tested). `DeepHudStyle.h` = every colour by role (Primary, Secondary, Alert, Amber, PanelFill, Shade), size and time; the only file with a colour value, the legacy canvas and harpoon overlay included. `SDeepHud` = one `SLeafWidget` on the player viewport that paints the frame in `OnPaint` (Roboto via `FCoreStyle::GetDefaultFontStyle`, 1080p units under the DPI scaler). New panel: a bit in `EDeepHudPanel`, add it to `PanelsFor`, a test in `DeepHudTests.cpp`, paint it in `SDeepHud::OnPaint`. `DeepUserSettings` = the player's volume, sensitivity, invert and ray tracing (Config=GameUserSettings, saved per user) and `Content/Data/Credits.csv`; menu keys and screens are in `ADeepPlayerController::HandleMenuKey`; `Deep.Screen settings|credits|quit` opens one.
- `Diver/` `ADeepDiver` (ACharacter: MOVE_Flying in the water, MOVE_Walking + gravity aboard via `SetAboard`; seated, the view target is the sub's helm camera; E = grab in water, use aboard; the lamp needs the flashlight), `DeepLamp` (the lamp up close: samples its whole cone, world rays + the serpent's `GetDrawnSpheres` + dressing boxes, and dims for the brightest point, `UDeepRules::LampSampleBrightness`; `Deep.Lamp.Near 1` = the old single ray; also the carried relic's glow), `UDeepTetherComponent` (TG_PostPhysics: winch, length clamp, depth from `SubDepthM`; drives the line, a `UDeepRopeComponent` (World/): a Verlet rope `Sim/DeepRopeSim` drawn as movable cylinder segments so it writes motion vectors, sags with slack (`UDeepRules::RopeShownLengthCm`), parts at the serpent's head or the hatch on a cut; the harpoon line is the same rope; DEEP Tuning > Rope; `Deep.Rope.Stage`, `Deep.Rope.State`), `UDeepRunComponent` (the run state machine, below).
- `Story/` `UDeepEventBus` (`Broadcast(name, payload)`; names in `DeepEvent::` = `event` column of `Content/Data/CaptainLines.csv`), `UDeepCaptain` (picks a line, subtitle queue by urgency). Radio Captain (D-040, `Deep.Captain.Radio 0|1`): `DeepCaptainPacing` = pure scene (title/aboard/water/settlement) + danger (calm/tense/scared) -> which urgencies show in the water; the CSV `tone` column picks the line for the danger (Captain|Radio tuning; `Deep.Story.Captain*` tests).
- `Monster/` the sea serpent (see `Monster/README.md`): pure rules, settings, `UDeepMonsterBrain` (spawns at stop >= 2), `ADeepSerpent` (procedural tube body, head socket, eyeshine, markings, its own glow in a bite (`Deep.Monster.Glow 0|1`); the Dragon Cave dragon as a clipped mesh head when the pack is installed, `Deep.Monster.MeshHead 0` = code head; materials in `Content/Deep/Serpent`, rebuilt by its .py files), `ADeepSerpentController` (keeps to the relic's shaft while its diver is in it: `UDeepMonsterRules::WellAimPoint`; elsewhere every aim and the path stay `CaveWallClearM` + `CaveBodyReachM` inside the cavern: `ADeepCavern::KeepClearCm`). It only hunts divers who can swim; aboard is safe.
- `Harpoon/` one shot per dive (LMB, mapped by the component itself; water only). `UDeepHarpoonRules` pure (range, reel step, bolt step, sphere hit, repair fee); `UDeepHarpoonSettings` (DEEP Harpoon); `UDeepHarpoonComponent` on the diver (server: bolt flight, latch, reel; on the sub it reels the diver up into the hatch, where the run brings it aboard; reloads on dive_start/respawn/descend; `harpoon_*` events); `ADeepHarpoonBolt`; `DeepHarpoonHUD::Draw`. Sub hits raise `HullDamage` and `HullRepairsOwed` (billed once in `Bank`).
- `World/` `ADeepSubmarine` = the fixed point and the room (box hull of cubes: deck around a hatch over the anchor, walls, ceiling, rim, red hatch cover when locked, console, helm, light, `HelmCamera`; helpers `GetHatchLocation`, `GetSolidBoundsLocal` (box of the colliding cubes = the visible hull), `IsInRoom`, `IsInHatchColumn`, `IsWithinUseRange`, `SetHatchOpen`). `DeepHull::Parts` = the sub's outside dress (frame, foam, tanks, skids, thrusters, arm, hatch well, tether bridle; ~142 basic shapes, visual only, within 60 cm of the colliding box, `Deep.World.SubHullDress`); the trench also shows through the window to a player in the room while the sub moves (`TrenchShows`). `ADeepArenaRoot` = what everything outside hangs from. `ADeepEnvironment` = the water look: each tick blends `FDeepLookTuning::Presets` (100/300/500 m, style guide 5) by `SubDepthM` into downlight, height + volumetric fog, locked exposure and grade; marine snow (ISM specks wrapped round the view, hung from the root so they stream past when driving); salvage glint scale; `Deep.RayTracing 0|1`. The sub adds the belly flood, bow lights, blinking markers and the hatch pool (`/Game/Deep/Look/M_HatchWater`); `SetOutsideLights` dims its outside lights by depth. `TickHelmLook`: while the helm is manned the bow lights become floods (Look|Helm), a code-built trench wall (`Trench`, `TrenchReliefM`, ledge every 10 m) slides past the helm camera by `SubDepthM`, sway scales with `GetDriveSpeedMps`, a settle on parking, and the stop's bed and salvage hide while the sub is below the loaded stop; the snow streaks by that speed in the helm view. `ApplyLook` dresses the room: worn steel on every cube (`DeepShapes::Steel`, `/Game/Deep/Room/M_WornSteel`, any mesh), amber screens, glass in the helm window, cool strips (two along the room, one across the nose: `Deep.Room.NoseStrip 0|1`), amber practicals, red at the hatch, and its own exposure inside `RoomVolume`. Room materials: `Content/Deep/Room/build_room_materials.py`. `ADeepAbyssFloor` = the sea bed: a procedural silt mesh round the anchor through every salvage spot's resting point (`SeabedBelowM`, pure), the relic in a sinkhole; `ADeepCavern` = rock walls and a roof round each stop (one procedural shell per stop, star-shaped round the anchor so relief only pushes rock out, 14 m roof opening over the sub for the shaft, `MakeMesh`/`SurfaceDistanceM`/`RoomM`/`KeepClearM` pure, blocks Visibility + Pawn only while shown, hides with the bed; `cave_` dressing rows hide with it); material by path (`Look.SeabedMaterial`, default `M_Silt`). Look materials are built by `Content/Deep/Look/build_look_materials.py`. `DeepArena::EnsureArena` spawns what the map lacks (sub, root, salvage ring, relic, floor, environment, dressing); `ApplySubDepth` moves the root by (SubDepthM - stop depth), loads the nearest stop's arena, opens the hatch only when parked. `ADeepDressing` = pack rock and ruin from `Content/Data/Dressing.csv` (place/scatter rows; ref bed/anchor/depth/wall; one HISM per mesh, no collision; pieces near a diver's path (hatch to each salvage spot, the shaft) are dropped unless low in the silt; re-placed when the loaded stop changes; skin `/Game/Deep/Dressing/M_DressSilt` gets each slot's pack textures via `DeepDressing::Skin`); its cook hook adds every asset the CSV and `PackAssets.csv` name. `Deep.Dressing.Sheet` (contact sheet), `Deep.Dressing.Hide` (frame-time A/B). `ADeepSalvage`: scrap shows as a pipe, a bent plate or a tank (`ScrapParts`, look only); the hidden box is the grab collider. `DeepShapes` = basic shapes + tint.

Units: names ending `M` are metres, `Cm` are Unreal units. Sub-relative layout is in metres in `FDeepSubTuning`.

How a run flows:
0. Title: `bOnTitle` holds every run component; the diver waits on the deck. Any key -> `StartRun` -> `BeginRun` (in the room: Aboard; a test diver spawned in the water: a first dive).
1. Aboard (Patience frozen, `idle_inside`): walk; E near the console = `UseConsole` (cargo: `Bank` -> Settling -> continue -> Aboard; none: buy the next gate if affordable); E near the helm = `TakeHelm` (`helm_take`). Falling into the open hatch = `LeaveSub` -> `StartDive(Hatch)`: Tethered, flying, salvage respawned, view pitched down to at least `Arena.HatchDropPitchDeg`, `dive_start`.
2. Helm (`StepHelm`, server): input > 0 dives at `DriveSpeedMps`, never past `DepthLimitM` (`helm_depth_limit`), `SubDepthM` changes, `ApplySubDepth` moves the root. Released within `ParkSnapM` of a stop: `Park` (`descend_stop2/3` first time, else `helm_arrive`). `Deep.Drive` uses the autopilot (it follows the passage's centre, no hits). With the shaft on, `StepShaft` (server, 0.05 s substeps): A/D/W/S steer `SubOffsetM` with inertia, the pure `Contact` pushes the sub out of the rock and bounces it, a knock dents `HullDamage` by impact speed (`hull_hit`, the helm camera jolts on every machine), rubbing dents slowly (`hull_damage`), under a quarter = `hull_critical`, at `HullBreachDamage` = `hull_breach`: the diver aboard dies (`DieFor`), the hull is patched and billed.
3. In the water: controller input -> diver Tick -> `SwimVelocityMps`. Tether after physics. Grab -> cargo, `NotifyPickup`. Patience drains (x2 hunted) and cuts at zero (`CutTetherFor` is the one Cut path); bailout air; death -> Dead -> `Respawn` aboard (DiverNumber+1).
4. Home = up through the hatch or arriving at the anchor (`ReachedHatch`) -> `EnterSub` (cut: re-tether fee). The view is levelled to `Arena.AboardPitchDeg`. Banking the relic at the console -> Won (review).
5. The serpent (stop 2+): see `Monster/README.md`; brain events are bound by each diver's run component.

Add a rule: a `static` UFUNCTION(BlueprintPure) in `UDeepRules`, numbers in a tuning struct, a test with a locally built tuning struct.
Add an event: `DeepEvent::` + `AllFired()`, rows in `CaptainLines.csv`, urgency in `UDeepCaptain::Urgency`, fire it with `Fire`/`FireChatter`.
Add a cheat: a `FAutoConsoleCommandWithWorldAndArgs` in `Debug/DeepCheats.cpp`, `Deep.<Verb>`, end with `DeepStateReport::LogState(World)`; new state = a key in `DeepStateReport::BuildJson`.
Cheats: `Deep.State`, `Deep.GiveSalvage <kg> <value>`, `Deep.GotoStop <n>`, `Deep.Teleport <x> <y> <z>`, `Deep.Hover <m>` (first surface in view at m), `Deep.Look <pitch> [yaw]`, `Deep.Lamp <0|1>`, `Deep.SetPatience`, `Deep.ForceCut`, `Deep.Bank`, `Deep.Continue`, `Deep.ResetRun`, `Deep.Title`, `Deep.Start`, `Deep.Credits <n>`, `Deep.Relic`, `Deep.Grab`, `Deep.Winch <0|1>`, `Deep.Win`, `Deep.Menu <0|1>`; sub: `Deep.EnterSub`, `Deep.Hatch`, `Deep.Console`, `Deep.Helm [0|1]`, `Deep.Drive <m|s1..s3> [now]`, `Deep.BuyGate [free]`, `Deep.Hull <0|1>` (outside dress A/B); serpent: `Deep.Monster.*`; harpoon: `Deep.Harpoon.Fire|AimSub [fire]|Reset`; cave: `Deep.Cave.Cavern 0|1` (0 = the open arena); audio: `Deep.Audio.List|Play <event>|Mute <0|1>|Reload`.
