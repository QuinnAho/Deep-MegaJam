# Inbox

Notes from humans to Claude.

- Add a dated line at the top of **New**.
- Claude reads this note at the start of each work block and acts on what is there.
- Claude then moves the line to **Handled**, with a one-line answer and a link to where the work or the answer lives.
- For anything longer than a few lines, write it in the Google Doc and leave a pointer here.

## Format

The lines below are an example only. They are not real messages.

```
New:
- 2026-11-15 09:10 EST | Colby | Can the monster ignore the lamp when the diver is carrying the relic?

Handled:
- 2026-11-15 09:10 EST | Colby | Can the monster ignore the lamp when the diver is carrying the relic?
  - Claude, 2026-11-15 09:25 EST: Added as a design question. See [[GDD]].
```
