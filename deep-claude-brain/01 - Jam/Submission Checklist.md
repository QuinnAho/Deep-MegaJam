# Submission Checklist

Target: **submitted by 8:00 PM EST on Sunday Nov 15**, one hour before the 8:59 PM cutoff. Uploads fail and forms time out.

## The build

- [ ] Packaged for Windows 10/11. Development build is what Epic recommends; Shipping is accepted.
- [ ] Zip named `TeamName_GameName.zip`. Team name still to be chosen.
- [ ] Under 1 GB. Larger builds need itch.io's butler tool.
- [ ] Runs on a second machine that has never had the project on it (Colby's PC).
- [ ] Plays from start to finish with no editor, no internet, no accounts and no API keys.
- [ ] Has a way to quit, and restarts cleanly after a death or a win.
- [ ] No API keys or secrets inside the package.

## The itch.io page and jam form

- [ ] Game uploaded to our own itch.io account, then submitted to the jam.
- [ ] Team name, and each member's name plus the email tied to their Epic Games account.
- [ ] Game name.
- [ ] Link to a **30 to 60 second gameplay video**.
- [ ] Dev log link. Optional in general, **required for Glass Box**.
- [ ] "Tools you used" filled in. This decides the Hyper3D cash pool and feeds the NVIDIA award.
- [ ] List of third-party assets and their licenses (Fab, Megascans, WeLoveIndies, generated models).
- [ ] NVIDIA questions answered, if we qualify: which features and how they were used.
- [ ] OpenAI question answered, if we qualify: which models or products and how.
- [ ] Attribution text included wherever a tool or asset requires it.

## Things to collect as we go

Keep these current so the form takes minutes, not an hour.

- **Tools used:** Unreal Engine 5.9 MegaJam Preview, Unreal MCP, Claude Code. Add each generator and library the moment it is first used.

## Rehearsal

Package and zip a build long before the deadline, and repeat every few hours. A build that has never been packaged is the most common way to miss a jam.
